# Refined Storage compile-time API

These jars are the official API artifacts of Refined Storage 2.0.9. They are used with
`compileOnly` so the storage binder can reach an RS network; they are not shipped with
VeinMinerPlus, and the mod still loads and runs without Refined Storage installed.

Source (GitHub release v2.0.9):
https://github.com/refinedmods/refinedstorage2/releases/tag/v2.0.9

Included modules: neoforge, common, core, storage, resource, network, autocrafting (all `-api`).
